40IGUAIS — APRESENTAÇÃO INTERATIVA

Para visualizar, abra o arquivo index.html em um navegador moderno.

Navegação:
- Role a página normalmente;
- Use as setas para cima e para baixo para avançar entre capítulos;
- Clique em “índice” para acessar uma seção diretamente;
- Na seção Identidade, arraste o logotipo horizontalmente.

O projeto é autocontido: imagens, fontes e código estão incluídos na pasta.
